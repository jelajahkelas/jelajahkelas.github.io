3. Putri punya beberapa stiker. Setelah diberi 28 stiker, jumlahnya menjadi 42. Kalimat matematika yang tepat …

  1. A.… × 28 = 42
  2. B.… + 28 = 42
  3. C.28 − … = 42
  4. D.42 + 28 = …
Lihat jawaban

Jawaban: B. … + 28 = 42. Stiker awal + 28 = 42, jadi stiker awal = 14.

4. 31 + … = 59

  1. A.23
  2. B.27
  3. C.28
  4. D.32
Lihat jawaban

Jawaban: C. 28. … = 59 − 31 = 28.
