Eksponen dan logaritma

Sifat eksponen, bentuk akar, fungsi eksponensial

1. Nilai 321/5 adalah …

  1. A.1
  2. B.4
  3. C.3
  4. D.2
Lihat jawaban

Jawaban: D. 2. a^(1/n) = ⁿ√a. 5√32 = 2.

2. Bentuk sederhana dari √32 adalah …

  1. A.4√2
  2. B.√18
  3. C.16√2
  4. D.2√4
Lihat jawaban

Jawaban: A. 4√2. √32 = √(16 × 2) = 4√2.

Barisan dan deret

Aritmetika, geometri, deret tak hingga, bunga

3. Tabungan Rp2.000.000 dengan bunga tunggal 10% per tahun. Besar bunga setelah 2 tahun adalah …

  1. A.Rp200.000
  2. B.Rp400.000
  3. C.Rp600.000
  4. D.Rp420.000
Lihat jawaban

Jawaban: B. Rp400.000. Bunga tunggal = M × i × t = 400.000.

4. Jumlah 15 suku pertama deret 5 + 8 + 11 + … adalah …

  1. A.392
  2. B.389
  3. C.394
  4. D.390
Lihat jawaban

Jawaban: D. 390. Sₙ = n/2 (2a + (n − 1)b) = 390.

Perbandingan trigonometri

Sin, cos, tan, sudut istimewa, elevasi

5. Nilai tan 45° adalah …

  1. A.√3
  2. B.½√3
  3. C.1/2
  4. D.1
Lihat jawaban

Jawaban: D. 1. Sudut istimewa: tan 45° = 1.

6. Segitiga siku-siku dengan sisi depan sudut α = 7, sisi samping = 24, sisi miring = 25. Nilai sin α adalah …

  1. A.25/7
  2. B.7/25
  3. C.7/24
  4. D.24/25
Lihat jawaban

Jawaban: B. 7/25. sin = depan/miring = 7/25.

Sistem persamaan dan pertidaksamaan linear

SPLTV dan daerah penyelesaian

7. Sistem persamaan dengan dua garis sejajar memiliki … penyelesaian

  1. A.satu
  2. B.tidak ada
  3. C.dua
  4. D.tak hingga
Lihat jawaban

Jawaban: B. tidak ada. Garis sejajar tidak berpotongan.

8. Titik yang memenuhi x + 2y ≤ 14 adalah …

  1. A.(15, 0)
  2. B.(14, 14)
  3. C.(0, 15)
  4. D.(0, 0)
Lihat jawaban

Jawaban: D. (0, 0). Substitusikan titik: 1×0 + 2×0 ≤ 14.

Persamaan dan fungsi kuadrat

Akar, diskriminan, titik puncak

9. Jumlah akar-akar persamaan x² + 6x + 5 = 0 adalah …

  1. A.−4
  2. B.−6
  3. C.−9
  4. D.−5
Lihat jawaban

Jawaban: B. −6. x₁ + x₂ = −b/a = −6.

10. Diskriminan persamaan 3x² + 2x + 6 = 0 adalah … , sehingga akarnya tidak real

  1. A.−70
  2. B.−68
  3. C.−69
  4. D.−73
Lihat jawaban

Jawaban: B. −68. D = b² − 4ac = 4 − 72 = −68.

Representasi dan interpretasi data

Statistik deskriptif dan korelasi

11. Median dari data 65, 61, 72, 92, 66, 82, 62 adalah …

  1. A.65
  2. B.66
  3. C.67
  4. D.68
Lihat jawaban

Jawaban: B. 66. Urutkan, lalu ambil nilai tengah: 66.

12. Median dari data 59, 62, 88, 84, 93, 73, 88 adalah …

  1. A.81
  2. B.84
  3. C.87
  4. D.83
Lihat jawaban

Jawaban: B. 84. Urutkan, lalu ambil nilai tengah: 84.

Peluang

Kejadian saling lepas dan saling bebas

13. Satu kartu diambil dari 52 kartu bridge. Peluang terambil kartu kartu bergambar (J, Q, K) adalah …

  1. A.12/13
  2. B.12/26
  3. C.1/12
  4. D.3/13
Lihat jawaban

Jawaban: D. 3/13. 12/52 = 3/13.

14. Kejadian A dan B saling bebas, P(A) = 1/2 dan P(B) = 1/4. P(A ∩ B) adalah …

  1. A.1/6
  2. B.3/4
  3. C.1/8
  4. D.1/3
Lihat jawaban

Jawaban: C. 1/8. Saling bebas: P(A) × P(B).
